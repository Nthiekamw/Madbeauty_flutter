Comment ça marche ?

Trois étapes pour une réservation sereine.

  1. Crée ton compte cliente ou prestataire sur l’application MadBeauty.
  2. Explore le catalogue, choisis une pro et sélectionne un créneau disponible.
  3. Confirme la demande : la prestataire valide, puis vous organisez le rendez-vous via le chat.
